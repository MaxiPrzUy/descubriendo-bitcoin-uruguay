# Start here

Bienvenido a Descubriendo Bitcoin Uruguay.

Este repositorio no está pensado como un archivo para “guardar documentos”. Está pensado como un **kit que se pueda entender, auditar y replicar**.

## Si tenés 2 minutos

Descubriendo Bitcoin es un programa educativo para personas que quieren entender Bitcoin desde cero.

No enseña trading ni recomienda inversiones.

Cada edición combina:

**educación + preguntas + caso real + medición + comunidad**

Y se organiza con el método D4:

**Descubrir → Debatir → Demostrar → Dar el siguiente paso**

## Si querés organizar una edición

No necesitás empezar desde cero.

### Antes

- definí la audiencia;
- elegí un espacio;
- prepará el contenido;
- seleccioná un caso real o invitado;
- imprimí las encuestas;
- prepará materiales y seguimiento.

### Durante

- bienvenida;
- encuesta inicial;
- Descubrir;
- Debatir;
- Demostrar;
- encuesta final;
- Dar el siguiente paso.

### Después

- registrá asistencia;
- compará resultados;
- documentá aprendizajes;
- compartí recursos;
- mantené un canal de continuidad;
- publicá un breve informe.

[Ver la guía completa →](04-replication-toolkit/how-to-replicate.md)

## Si estás auditando o evaluando el proyecto

Buscá cuatro cosas:

**1. Método**  
Cómo se estructura la experiencia educativa.

**2. Evidencia**  
Qué eventos ocurrieron realmente y qué se documentó.

**3. Medición**  
Cómo se compara el punto de partida y el resultado.

**4. Replicabilidad**  
Qué necesita otra comunidad para ejecutar una edición por su cuenta.

El objetivo es que cada nueva edición deje datos, aprendizajes y materiales que mejoren la siguiente.

## Un principio central

> Bitcoin no se aprende de golpe. Se aprende por capas.

Este repositorio sigue la misma lógica: podés entrar por el nivel que necesites y profundizar después.
