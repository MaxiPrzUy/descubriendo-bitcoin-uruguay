# Encuesta de entrada

**ANÓNIMA · aproximadamente 3 minutos**

Esta encuesta se realiza antes de la clase para conocer el punto de partida de cada participante.

No pedimos nombre, email, wallet ni datos financieros.

## Código de participante

Pedile a cada persona que use un código anónimo y que repita el mismo código en la encuesta de salida.

Esto permite comparar resultados sin identificar a la persona.

### 3. ¿Qué es una frase semilla?

### 4. ¿Qué afirmación sobre Bitcoin es más correcta?

### 5. ¿Qué afirmación describe mejor la emisión de bitcoin?
