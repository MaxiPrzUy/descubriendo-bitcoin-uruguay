# Descubriendo Bitcoin Uruguay

**Educación Bitcoin abierta, no especulativa, medible y replicable.**

Descubriendo Bitcoin Uruguay es un programa educativo impulsado por Plugin para ayudar a personas que parten desde cero a entender Bitcoin con claridad, pensamiento crítico y herramientas prácticas.

> No trading. No promesas de rentabilidad. No asesoramiento financiero.

## Qué es

Un programa de educación Bitcoin para nuevas audiencias, con encuentros presenciales, materiales abiertos, medición antes y después de cada actividad y continuidad comunitaria.

El recorrido introductorio empieza antes de Bitcoin: historia del dinero, problemas del sistema fiat, nacimiento de Bitcoin, funcionamiento básico, autocustodia, seguridad, casos reales y próximos pasos.

## Qué no es

- No es un curso de inversión.
- No es un programa de trading.
- No recomienda comprar bitcoin.
- No promete rentabilidad.
- No reemplaza asesoramiento financiero, legal o tributario.
- No busca cerrar debates: busca dar herramientas para comprenderlos mejor.

## Método D4

**Descubrir → Debatir → Demostrar → Dar el siguiente paso**

**Curiosidad → Comprensión → Experiencia → Comunidad**

El método organiza cada encuentro para que la experiencia no termine en una charla unilateral: primero se introduce el tema, después se abre la conversación, luego se conecta con un caso o experiencia real y finalmente se ofrecen caminos concretos para seguir aprendiendo.
